# Models

Do not store large model files in this repository unless they are tiny fixtures.

For each model used in experiments, record:

- Source model name and URL or local source.
- Original format, such as ONNX, PyTorch, or TensorFlow.
- Conversion command and RKNN toolkit version.
- Target platform, such as RK3588 or RK3576.
- Quantization settings.
- Runtime validation result.
