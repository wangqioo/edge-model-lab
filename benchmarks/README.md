# Benchmarks

Benchmark records should include:

- Device ID from `devices.yaml`.
- Model name and model artifact version.
- Runtime backend, such as RKNN Lite, systemd service, or Docker Compose.
- Input shape and batch size.
- Latency p50/p95/p99.
- Throughput.
- Memory usage.
- NPU/GPU/CPU temperature before and after.
- Notes about throttling or errors.
